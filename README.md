# Improve AI Prompt Clarity

This example simulates how the clarity and specificity of a prompt affect an AI model's response. It demonstrates that vague or ambiguous inputs lead to generic or unhelpful outputs, while well-structured and detailed prompts yield precise and relevant answers. The Python script illustrates common prompt errors and their improved versions.

## Language

`python`

## How to Run

Save the code as `main.py`. Open a terminal or command prompt, navigate to the directory where you saved the file, and run `python main.py`.
